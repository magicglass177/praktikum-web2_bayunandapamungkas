### Catatan Kasus Uji

| No. | Kasus Uji                   | Catatan Hasil Pengujian                                                                                                                                                                              |
| --- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Create valid                | Data tiket berhasil dibuat dengan status `open`. Ticket dan satu komentar awal berhasil tersimpan.                                                                                                   |
| 2   | Input kosong                | Validasi server berhasil menolak input kosong dan tidak terjadi penambahan data pada database.                                                                                                       |
| 3   | Input spasi                 | Input yang hanya berisi spasi di-trim dan ditolak oleh validasi `required`. Database tidak berubah.                                                                                                  |
| 4   | Batas subject               | Subject 149 dan 150 karakter berhasil disimpan, sedangkan 151 karakter ditolak dengan validasi maksimal 150 karakter.                                                                                |
| 5   | Batas description/note      | Description 5000 dan note 1000 karakter berhasil disimpan. Description 5001 dan note 1001 karakter ditolak oleh validasi.                                                                            |
| 6   | Identifier relasi tidak sah | `category_id` yang tidak tersedia dan nilai `abc` ditolak. `user_id` yang tidak tersedia pada create juga ditolak. Tidak ada perubahan database.                                                     |
| 7   | Identifier route tidak sah  | Route dengan ID non-numerik dan ID numerik yang tidak tersedia menghasilkan `404 Not Found`. Tidak ada data yang berubah.                                                                            |
| 8   | Update valid                | Subject, category, dan status berhasil diperbarui. ID dan pemilik tiket tetap sama serta komentar bertambah satu.                                                                                    |
| 9   | Update invalid              | Subject 151 karakter ditolak. Subject dan status lama tetap serta tidak ada komentar tambahan.                                                                                                       |
| 10  | Manipulasi field terlarang  | `status=closed` pada create dan `user_id` pada update ditolak dengan validasi `prohibited`.                                                                                                          |
| 11  | Input tambahan tanpa rule   | Field tambahan yang tidak memiliki rule tidak ikut disimpan karena controller menggunakan `validated()` dan service memetakan field secara eksplisit.                                                |
| 12  | Urgensi                     | Checkbox urgent yang dicentang tersimpan sebagai `true/1`, sedangkan saat tidak dicentang tersimpan sebagai `false/0`. Nilai `abc` ditolak oleh validasi.                                            |
| 13  | Delete sukses               | Tiket dengan status `open/pending` berhasil dihapus dengan redirect `303`. Tiket dan seluruh komentar terkait ikut terhapus.                                                                         |
| 14  | Delete ditolak              | Tiket berstatus `closed` tidak dapat dihapus. Tiket dan komentar tetap tersimpan di database.                                                                                                        |
| 15  | Rollback multi-tabel        | `TicketTransactionTest` berhasil dengan 1 test dan 10 assertions. Create dan update di-rollback ketika pembuatan komentar gagal.                                                                     |
| 16  | PRG dan refresh             | Setelah create berhasil, request menghasilkan `303` lalu `GET 200`. Refresh halaman detail hanya melakukan GET dan tidak menambah ticket/comment.                                                    |
| 17  | Escaping output             | Subject `<b>Uji</b>` ditampilkan sebagai teks literal, bukan sebagai teks tebal. Output berhasil di-escape oleh Blade.                                                                               |
| 18  | CSRF dan tipe data salah    | Request tanpa `_token` menghasilkan `419` dan tidak mengubah database. Subject yang dikirim sebagai array ditolak oleh validasi sebagai tipe data yang tidak sesuai, bukan menghasilkan error `500`. |
