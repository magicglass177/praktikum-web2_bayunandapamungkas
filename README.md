# Praktikum Pemrograman Web 2

## Deskripsi

Project ini dibuat untuk memenuhi praktikum mata kuliah Pemrograman Web 2.

Aplikasi menggunakan Laravel sebagai backend/API dan Vue.js dengan Vite sebagai frontend.

## Teknologi

- PHP
- Laravel
- Composer
- Vue.js
- Vite
- Node.js
- NPM
- Git
- Database
